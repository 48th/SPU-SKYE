# พยากรณ์ PM2.5 รายสถานีกรุงเทพฯ ด้วย Extra Trees

ชุดนี้ต่อยอดจาก `main(1).py` และ `live_data(2).py` ใช้ Python 3.12 และ SQLite รันคำสั่งจากโฟลเดอร์นี้

## รัน API และเก็บข้อมูล

```powershell
python -m pip install -r requirements.txt
python -m uvicorn main:app --host 127.0.0.1 --port 8000
```

- เปิด `http://127.0.0.1:8000/live?station_id=02T` เพื่อดูค่าล่าสุดและพยากรณ์ โดยหน้าเว็บเช็กข้อมูลใหม่ทุก 1 นาที
- `GET /health` แสดงสถานะโมเดลเดิมและจำนวนโมเดล Extra Trees รายสถานี
- `GET /api/v1/stations` แสดงสถานีและค่าที่ Air4Thai รายงานล่าสุด
- `GET /api/v1/forecast?station_id=02T` แสดงผลหรือเหตุผลรายสถานี ถ้าเว้นรหัสจะแสดงทุกสถานีในฟีด ใช้ `horizon=tomorrow` หรือ `24h` ตามสัญญาเดิม ทั้งสองค่าอ้างถึงวันปฏิทินถัดไปตามเวลาไทย
- `GET /api/v1/evaluation` แสดงผลรวม ผลรายสถานี และจำนวนข้อมูลที่ผ่านเงื่อนไข
- `POST /predict` ยังรองรับโมเดลเดิมเมื่อกำหนด `PM25_MODEL_PATH` ไปที่ไฟล์เดิมที่เชื่อถือได้

ระหว่างที่ API ทำงาน ตัวเก็บข้อมูลจะดึง Air4Thai ทุก 15 นาทีและบันทึกลง `air4thai_latest` โดยใช้รหัสสถานีและเวลาที่รายงานเป็นกุญแจกันข้อมูลซ้ำ เมื่อเชื่อมต่อไม่ได้จะลองอีกครั้งหลัง 1 นาที คำสั่ง `python station_forecast.py collect` ใช้ดึงหนึ่งรอบได้ ฟีดล่าสุดไม่ได้ระบุช่วงเวลาเฉลี่ยในรายการ PM2.5 การพยากรณ์รายวันจึงใช้ข้อมูลจาก `station_daily` [ชุดข้อมูลฟีด Air4Thai](https://naturebi.mnre.go.th/ckan/dataset/air4thai)

สร้างโฟลเดอร์ `daily_inbox` ข้าง `main.py` แล้ววางไฟล์ Excel รายวันที่ตรวจสอบแล้ว ตัวเก็บข้อมูลจะนำเข้าระหว่างที่ API ทำงานและพยากรณ์ได้ทันทีเมื่อสถานีนั้นมีข้อมูลครบ 14 วันก่อนวันออกพยากรณ์ สามารถตั้งตำแหน่งโฟลเดอร์ด้วย `PM25_DAILY_INBOX` หากต้องการเปิดตลอด ให้รัน API บนเครื่องหรือเซิร์ฟเวอร์ที่เปิดตลอดและเก็บฐานข้อมูลไว้บนพื้นที่ถาวร

## เพิ่มข้อมูลรายวันและฝึกใหม่

```powershell
python station_forecast.py import-xlsx "C:/path/to/2025.xlsx" "C:/path/to/2026.xlsx"
$env:PM25_STATION_MODEL_PATH = "$PWD/models/station_extra_trees_v2.joblib"
python station_forecast.py train
python -m uvicorn main:app --host 127.0.0.1 --port 8000
```

ตัวนำเข้ารองรับไฟล์รูปแบบเดียวกับ Excel ที่พบใน Downloads โดยอ่าน `DATA` ที่มีวันที่กับคอลัมน์รหัสสถานี และใช้ชีต `รายละเอียดจุดตรวจวัด` คัดกรองสถานีกรุงเทพฯ ใช้เฉพาะไฟล์รายวันที่ตรวจสอบที่มา หน่วย µg/m³ และนิยามวันที่แล้ว ค่าว่างถูกข้าม ค่าวันซ้ำหรือค่าที่ขัดแย้งกันจะหยุดการนำเข้า ไฟล์ชุดนี้มีข้อมูลรายวัน 6,046 ค่าในกรุงเทพฯ ถึง 30 มิถุนายน 2026 สามารถกำหนดฐานข้อมูลผ่าน `PM25_STATION_DB` และกำหนดไฟล์โมเดลใหม่เมื่อฝึกซ้ำ

เมื่อขอพยากรณ์ในวันที่ D เป้าหมายคือค่าเฉลี่ยรายวันของ D+1 โมเดลใช้ค่าจริงจาก D−1 ถึง D−14 ของสถานีเดียวกันเพื่อสร้าง lag และ rolling mean พร้อมเดือนของวันเป้าหมาย ถ้าวันใดขาดหรือสถานียังไม่มีโมเดล API จะรายงานเหตุผล ใช้ข้อมูลฝุ่นกับปฏิทินในโมเดลรุ่นนี้ การจะเพิ่ม Open-Meteo ต้องมีข้อมูลพยากรณ์อากาศที่ทราบเวลาออกพยากรณ์ย้อนหลัง เพื่อให้สร้าง feature ตอนฝึกและตอนใช้งานด้วยเงื่อนไขเดียวกัน

## ผลตรวจและข้อจำกัด

- `PM25_model_bundle.joblib` เดิมโหลดได้ด้วย scikit-learn 1.8.0 เป็น `Tuned Random Forest` และมี 29 features รวม PM10 สภาพอากาศ และ US AQI ส่วน `PM25_bkk_calibrated_bundle.joblib` เป็นชุด GBDT หลายระยะ รายงานเดิมอาศัยข้อมูลกริดที่ปรับตามสถานี โมเดล Extra Trees ที่ให้มานี้ฝึกจากข้อมูลรายวันใน Excel
- ผลทดสอบตามลำดับเวลา 2 พฤษภาคม ถึง 30 มิถุนายน 2026 มี 638 คู่สถานี–วัน จาก 11 สถานี Extra Trees ได้ MAE 2.907 และ RMSE 3.622 µg/m³ ส่วนการใช้ค่า D−1 ตรง ๆ ได้ MAE 2.685 และ RMSE 3.499 µg/m³ บนคู่สถานี–วันเดียวกัน ผลนี้เป็นผลย้อนหลังภายใต้สมมติฐานว่าค่ารายวันก่อนวันออกพยากรณ์พร้อมใช้งาน เนื่องจากไฟล์ Excel ไม่มีเวลาที่เผยแพร่จริง
- ฐานข้อมูลเริ่มต้นสิ้นสุดวันที่ 30 มิถุนายน 2026 จึงต้องนำเข้าค่าเฉลี่ยรายวันล่าสุดก่อนจึงจะพยากรณ์สำหรับวันถัดไปได้
